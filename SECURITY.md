# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x | Yes |

## Reporting a Vulnerability

Do not report security vulnerabilities through public GitHub issues, discussions, or pull requests. Public disclosure before a fix is available puts users at risk.

Report privately through the repository's security advisory channel. Include:

- A description of the vulnerability and its impact
- Steps to reproduce, with a proof of concept if possible
- Affected version or commit
- Any suggested mitigation

Do not include real credentials, cookies, browser profile contents, private drafts, or account screenshots unless a maintainer explicitly asks for a redacted sample through a private channel.

## What to Expect

Maintainers will acknowledge reports as soon as practical, investigate, and coordinate a fix and disclosure timeline with the reporter.
