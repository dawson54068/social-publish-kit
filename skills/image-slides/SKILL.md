# Image Slides

Plan a coherent carousel from the supplied source. Each slide must have one job: hook, context, key idea, steps or example, caveat, and takeaway. Use the same visual system throughout and keep text legible at phone size.

Read `references/config-contract.md` when configuration is supplied. A configured handle, logo, domain, or color system may be used; absent values remain absent.

## Output

Create one prompt file per slide in the caller's chosen output directory. Use zero-padded names such as `01-cover.prompt.txt`. Never insert a personal handle, logo, domain, or signature unless the user supplies it in the current request or config.

Before rendering, list the slide order and flag any source detail that is ambiguous. Do not invent text to fill a slide.
